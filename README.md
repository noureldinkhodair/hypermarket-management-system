# 🛒 Hypermarket Management System

A full-featured Hypermarket Management System developed using PHP, MySQL, Object-Oriented Programming (OOP), MVC Architecture, and Design Patterns to streamline supermarket operations and improve management efficiency.

---

## 🚀 Features

### 👤 Customer Features
- 🔐 User Registration & Login
- 🛍 Browse Products by Categories
- ❤️ Add Products to Favorites
- 🛒 Shopping Cart Management
- 📦 Place Orders
- 📞 Contact Support

### 👨‍💼 Admin Features
- 📊 Admin Dashboard
- 📦 Product Management

## ⚙️ How to Run Locally

### 1. Install Requirements
- XAMPP / WAMP / MAMP
- PHP
- MySQL

### 2. Clone Repository

```bash
git clone https://github.com/noureldinkhodair/seoudi-market-management-system.git
```

### 3. Move Project

Place the project folder inside:

```text
htdocs/
```

### 4. Import Database

Open phpMyAdmin and import:

```text
seoudi_market.sql
```

### 5. Run Application

Open your browser and navigate to:

```text
http://localhost/seoudi_market/
```
